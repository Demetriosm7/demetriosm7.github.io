Who Am I?

I'm Demetrios Michael, a Front-End Web Developer based in the Charlotte, North Carolina area of the United States.

I enjoy building responsive, user-friendly websites using modern web technologies and mobile-first design principles. I focus on creating clean interfaces, improving user experience, and continuously strengthening my frontend development skills through hands-on projects.

Design

I focus on creating clean and visually engaging interfaces that prioritize usability, responsiveness, and modern design principles. My goal is to build websites that feel intuitive and accessible across all devices.

Develop

I build responsive websites using HTML5, CSS3/SCSS, JavaScript, Flexbox, CSS Grid, and Git/GitHub. I focus on writing clean, maintainable code while continuing to expand my frontend development skills through hands-on learning.

Deploy

I take pride in creating responsive and user-friendly projects that are functional across multiple devices and screen sizes. Seeing a project evolve from an idea into a polished final product is one of the most rewarding parts of development.

Front-End Skill Set

I primarily work with HTML5, CSS3/SCSS, JavaScript, responsive design principles, Flexbox, CSS Grid, Git/GitHub, Bootstrap, and UI-focused frontend development. My focus is on building clean, responsive interfaces while continuing to strengthen my JavaScript and frontend development skills through practical projects.

Expanding My Knowledge

My Availability
